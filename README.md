 
# 🛍️ E-commerce Product Page

![Design preview](https://res.cloudinary.com/dz209s6jk/image/upload/f_auto,q_auto,w_700/Challenges/xde5z4efoocyw2mcuqod.jpg)

A clean and interactive e-commerce product page built as part of the [Frontend Mentor Challenge](https://www.frontendmentor.io/challenges/ecommerce-product-page-UPsZ9MJp6). This responsive page includes features like a product image gallery, lightbox modal, cart functionality, and mobile-friendly design.

## 🚀 Live Demo

👉 [View Live Site](https://your-deployment-link.com)

---

 
---

## 📦 Features

- ✅ Fully responsive layout (mobile, tablet, desktop)
- 🖼️ Product image gallery with thumbnails
- 🔍 Lightbox modal for product image zoom
- 🛒 Add to cart functionality with item quantity
- 🧹 Remove items from cart
- 🌙 Clean and modern design
- 💻 React + Tailwindcss

---


## 📌 Challenge Requirements

From Frontend Mentor:

* View the optimal layout for the site depending on their device’s screen size
* See hover states for all interactive elements on the page
* View and switch between product images in the gallery
* Add items to the cart
* View the cart and remove items
* Lightbox modal for larger images (desktop only)
